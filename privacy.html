「南海トラフ 津波避難診断」(以下「当サイト」)で入力された情報の扱いと、診断に使っている数値の出典をまとめています。

1. 取得する情報と使い道

当サイトは、診断のために次の情報を入力・取得します。当サイトの運営者のサーバーに送ったり、保存したりすることはありません。処理はすべて利用者の端末(ブラウザ)の中で行います。

  • 都道府県・市区町村の選択:市区町村ごとの津波想定を表示するために使います。外部には送りません。
  • 詳しい住所(任意):その地点が津波浸水想定区域に入るかを調べるために使います。後述の国土地理院の住所検索に送ります。
  • 現在地(任意):「現在地で調べる」を押したときだけ取得し、市区町村の判定と浸水想定区域の判定に使います。

氏名・電話番号・メールアドレスなど、個人を特定する情報の入力欄はありません。

2. 外部のサービスに送られる情報

当サイトの機能を使うと、次の外部サービスに情報が送られます。送られた情報の扱いは、各サービスの方針に従います。

送り先送られる情報送られるとき

各サービスの方針:国土地理院/Google/GitHub(当サイトの配信元)

3. 位置情報(現在地)

  • 現在地は、「📍 現在地で調べる」を押し、ブラウザの確認画面で利用者が許可したときだけ取得します。
  • 取得した緯度・経度は、その場の判定に使うだけで、端末にも当サイトにも保存しません。
  • 許可はブラウザや端末の設定から、いつでも取り消せます。

4. 端末への保存・Cookie・アクセス解析

  • Cookie とアクセス解析ツールは使っていません。広告も表示していません。
  • 津波想定地域一覧のページでは、使いやすさのため、選んだタブ・都道府県・並べ替え・絞り込みの条件だけをブラウザの保存領域(localStorage)に保存します。住所や位置情報は保存しません。ブラウザのサイトデータを消すと削除されます。
  • 当サイトは GitHub Pages で配信しています。配信元の GitHub 社が、アクセスの記録(IPアドレスなど)を取得することがあります。

6. 免責事項

  • 当サイトの数値は、公表された想定をもとにした目安です。実際の津波の高さ・到達時間と一致するとは限りません。
  • 住所の位置は町名の中心などになることがあり、地点の判定は正確でない場合があります。
  • 当サイトの情報を使ったことで生じた損害について、運営者は責任を負いかねます。強い揺れを感じたら、数値にかかわらず、警報を待たずにすぐ高い場所へ避難してください。

7. このポリシーの変更

機能の追加やデータの更新にあわせて、このページの内容を変更することがあります。変更後の内容は、このページに掲載した時点から適用します。
